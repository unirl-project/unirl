This setup is optional and legacy. Run it only for the legacy
GenEval/OpenMMLab scorer, in a **separate Python 3.10 sidecar environment**.
Do not install this MMCV stack into UniRL's core Python 3.12 / CUDA 13 engine
environment.

## Why separate?

`mmcv` 1.x / `mmdet` 2.x belong to an older Python/PyTorch/CUDA compatibility
window. Keeping the scorer behind a service/process boundary prevents those
pins from downgrading or breaking the core environment.

## Recommended versions

- `mmcv` tag: `v1.7.2`
- `mmdetection` branch: `2.x` (currently `2.28.2` in our validated env)

These versions match the validated local setup used in this repository.

## Install steps

Create and activate a Python 3.10 environment first. Choose a PyTorch/CUDA
build compatible with the sidecar host; it does not need to match the core
training environment.

```bash
uv venv --python 3.10 --seed .venv-geneval
source .venv-geneval/bin/activate

pip install -U openmim
mim install mmengine

cd ~/mmgrpo
git clone https://github.com/open-mmlab/mmcv.git
cd mmcv
git checkout tags/v1.7.2
MMCV_WITH_OPS=1 FORCE_CUDA=1 pip install -e . -v
cd ..

git clone https://github.com/open-mmlab/mmdetection.git
cd mmdetection
git checkout 2.x
pip install -e . -v
cd ..
```

## Sanity check

```bash
python -c "import mmcv, mmdet; print('mmcv', mmcv.__version__); print('mmdet', mmdet.__version__); from mmcv.ops import nms; print('mmcv.ops ok')"
```

Expected:

- `mmcv` reports `1.7.2`
- `mmdet` reports a `2.x` version (e.g., `2.28.2`)
- `mmcv.ops ok` prints without import errors
