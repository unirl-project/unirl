## Quality Signal During Training

The reward components configured on a recipe are the primary quality signal.
Each rollout scores generated media and logs per-sample and per-component reward
(visible in WandB when enabled). Built-in scorers under `unirl/reward/local/`
include PickScore, HPS, OCR, GenEval2, VideoPickScore, and rule-based matchers.

See [Rewards](/en/docs/guides/rewards) for configuration and the generated
[Reward Package README](/en/docs/guides/readme-reward-package).

## Periodic Evaluation

Periodic evaluation is implemented for diffusion, AR, and SFT trainers. Set
`eval_interval` above zero in the recipe; `0` disables it.

- `data_source.args.run.eval_data_path` selects a deterministic, unshuffled eval
  source. Recipes commonly interpolate `EVAL_DATA_PATH`.
- Diffusion/AR use `eval_num_prompts` and evaluation-specific sampling knobs.
  Diffusion also supports chunking and `eval_rewards`, a list of extra reward
  suites that may share the default eval set or specify their own.
- SFT uses `eval_batch_size` and `eval_num_samples`; `-1` evaluates the complete
  eval set.
- Evaluation runs at step/rollout zero and at the configured cadence where the
  trainer supports it. Async trainers drain to a synchronized empty-rollout
  boundary before evaluating.

Use the selected recipe as the exact source of truth because available knobs
differ by trainer.

## Offline / External Benchmarks

The `[eval]` extra installs the current OCR reward dependencies: PaddlePaddle,
PaddleOCR, torchvision, and Levenshtein support. It is not a general benchmark
harness.

The legacy GenEval/OpenMMLab scorer must run as a Python 3.10 sidecar, separate
from the core Python 3.12 / CUDA 13 engine environment. Follow
[Geneval MMCV Setup](/en/docs/guides/geneval-mmcv-setup); do not install its
MMCV stack into a core training environment.

## If You Need Eval Now

- Enable the trainer's periodic eval fields and read `eval/*` metrics in W&B.
- Add an `eval_rewards` suite when diffusion eval needs additional scorers.
- Or score generated media offline with the standalone reward service in
  `unirl-reward-service/`.
