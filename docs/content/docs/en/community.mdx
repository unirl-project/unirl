UniRL is developed in the open. If you are using UniRL, want to contribute, or
just have questions, the fastest way to reach the maintainers and other users is
the WeChat developer group.

## WeChat Developer Group

Scan the QR code below with WeChat to join the **UniRL 开发者讨论群** (UniRL
Developer Discussion Group).

<CommunityQR
  src="/community/wechat-qr.jpg"
  alt="WeChat QR code for the UniRL developer discussion group"
  caption="UniRL 开发者讨论群 · scan with WeChat to join"
/>

The QR code is refreshed periodically. If it has expired, please open an issue on
GitHub and we will update it.

## Other Channels

- **GitHub Issues** — bug reports, feature requests, and design discussion. See the
  [GitHub Issues Workflow](/en/docs/others/github-issues-workflow) for conventions.
- **Documentation** — start from the [Agent Index](/en/docs/agents) or the
  [getting started](/en/docs/getting-started/installation) guides.
