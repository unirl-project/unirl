这组依赖是可选的 legacy 路径。只有 legacy GenEval/OpenMMLab scorer 需要它，并且必须
在**独立 Python 3.10 sidecar 环境**中运行。不要把这套 MMCV 依赖装进 UniRL 核心
Python 3.12 / CUDA 13 engine 环境。

## 为什么单独安装

`mmcv` 1.x / `mmdet` 2.x 属于较旧的 Python/PyTorch/CUDA 兼容窗口。通过 service/process
边界隔离 scorer，才能避免它们降级或破坏核心训练环境。

## 推荐版本

- `mmcv` tag: `v1.7.2`
- `mmdetection` branch: `2.x`，验证环境中常见版本是 `2.28.2`

## 安装步骤

先创建并激活 Python 3.10 环境。PyTorch/CUDA 构建应匹配 sidecar 所在主机，无需与核心
训练环境相同。

```bash
uv venv --python 3.10 --seed .venv-geneval
source .venv-geneval/bin/activate

pip install -U openmim
mim install mmengine

cd ~/mmgrpo
git clone https://github.com/open-mmlab/mmcv.git
cd mmcv
git checkout tags/v1.7.2
MMCV_WITH_OPS=1 FORCE_CUDA=1 pip install -e . -v
cd ..

git clone https://github.com/open-mmlab/mmdetection.git
cd mmdetection
git checkout 2.x
pip install -e . -v
cd ..
```

## Sanity Check

```bash
python -c "import mmcv, mmdet; print('mmcv', mmcv.__version__); print('mmdet', mmdet.__version__); from mmcv.ops import nms; print('mmcv.ops ok')"
```

期望结果：

- `mmcv` 为 `1.7.2`
- `mmdet` 为 `2.x` 版本
- `mmcv.ops ok` 正常打印
